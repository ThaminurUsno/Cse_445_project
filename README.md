# Cse_445_project
Dataset:

Dhaka Obesity: Dataset based on Eating Behavior and Physical Conditions Link: https://data.mendeley.com/datasets/vhnks4n4h7

2,182 records, 17 columns (2,157 after removing duplicates)
Features: gender, age, height, weight, family history of overweight, high-calorie food, vegetable intake, main meals per day, snacking between meals, smoking, alcohol, water intake, calorie monitoring, physical exercise, device usage time, mode of transportation
Target: Obesity level (Insufficient_Weight, Normal_Weight, Overweight, Obesity_Type_I, Obesity_Type_II, Obesity_Type_III)
